# RAES API

Servicio central de integración.

Responsabilidades previstas:

- autenticación institucional;
- validación de scopes;
- validación de contratos;
- idempotencia;
- registro de sedes, programas, personas y credenciales;
- versionado y eventos;
- correcciones, revocaciones y anulaciones;
- consultas autorizadas para Credenly.

Credenly consultará la información académica a través de esta API y no mediante acceso directo a la base de RAES.
